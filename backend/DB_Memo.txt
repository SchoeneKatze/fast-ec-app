1. 用户表 (users) - 关联 Logto
不存储密码，只存储业务相关的用户信息。

internal_id: INT (PK) - 内部自增 ID。

logto_id: VARCHAR (Unique) - 存 Logto 提供的 sub。这是关联 Logto 的唯一标识。

password: VARCHAR - although not be used, just set a volumn here

email VARCHAR - 从 Logto 同步。

phone_no VARCHAR - 从 Logto 同步。

nickname: VARCHAR(100) - 用户昵称。

gender / birthday: ENUM / DATE - 性别与生日。

default_currency: VARCHAR(3) - 用户偏好的币种代码（如 JPY, USD）。

role: ENUM - 用户角色（customer, VIP, staff, admin）。

created_at - DATE

deleted_at -DATE

last_login - DATE

isActive BOOLEAN- 删除帐号也不物理删除数据库，而是变换flag

2. 商品分类表 (categories)
id: INT (PK)

name: VARCHAR - 分类名称。

parent_id: INT (Self-FK) - 父分类 ID，支持无限极分类。

image_url: VARCHAR - 分类的小图标或封面图。

3. 商品主表 (products) - 存“裸价”
product_id: VARCHAR (PK) - 建议用 UUID 或业务 ID，方便迁移。

category_id: INT (FK) - 所属分类。

title / description: VARCHAR / TEXT - 标题与详细描述。

base_price: DECIMAL(12, 2) - 税前净价。 核心计价基准。

tax_class: ENUM - 税种分类（如 Standard, Reduced, Zero）。

stock_quantity: INT - 当前库存。

brand_id

sku_internal_code: VARCHAR - 内部库存单位编码。

barcode: VARCHAR - 条形码。

origin_country: VARCHAR - 产地。

weight / dimensions: FLOAT / VARCHAR - 涉及运费计算的物理参数。

created_at : DATE

isActive : BOOLEAN

4. 币种汇率表 (currencies)
currency_code: VARCHAR(3) (PK) - 货币代码（USD, CNY）。

currency_symbol: VARCHAR(5) - 符号（$, ¥）。

exchange_rate: DECIMAL(12, 4) - 相对本位币的汇率。

is_default: BOOLEAN - 是否为系统本位币。

5. 税率配置表 (tax_settings)
id: INT (PK)

country_code: VARCHAR(2) - 国家代码（CN, US, JP）。

tax_class: ENUM - 对应商品表的税种。

rate: DECIMAL(5, 4) - 税率（如 0.1000 代表 10%）。

is_show_inclusive: BOOLEAN - 关键： 该地区习惯是否为价内税（含税显示）。

6. 购物车表 (cart_items) - 数据库持久化
id: INT (PK)

user_id: INT (FK) - 关联本地 users.id。

product_id: VARCHAR (FK) - 关联 products.id。

quantity: INT - 放入的数量。

updated_at: TIMESTAMP - 方便清理长时间未下单的僵尸购物车。

7.product_images 表：
product_id : VARCHAR(ON DELETE CASCADE)

image_id : (increasing)

image_url : TEXT

8. 商品评论/评分表 (product_reviews)

id, product_id, user_id, rating (1-5), comment, created_at。

 (关联 tax_settings)

1. 币种（Currency）的确定逻辑币种的优先级通常如下（从高到低）：用户手动选择（最高优先级）：在你的网购网站顶栏，通常有一个切换币种的下拉菜单。一旦用户选择了（比如选了 JPY），我们就存入 localStorage 或数据库 users.default_currency。用户账号设置：如果用户登录了，且之前在个人中心设置过“偏好币种”，则以数据库为准。地理位置自动识别：如果用户是游客且没选过，后端通过 IP 地址 识别国家。如果是日本 IP，默认显示 JPY；如果是美国 IP，默认显示 USD。系统默认值（保底）：如果以上都失效，显示你网站的“本位币”（比如 USD）。2. 国家/地区（Country/Region）的确定逻辑国家决定了税率计算规则。它的确定逻辑更加严格：收货地址（Checkout 阶段，最高优先级）：这是最准确的。当用户进入购物车点击结账，填入了“东京都港区...”时，系统必须立即切换到日本的税率。IP 地理位置（浏览阶段）：在用户还没下单、只是逛网站时，后端通过 Cloudflare 或 GeoIP 数据库识别请求头里的 IP。逻辑示例：FastAPI 拿到请求 $\to$ 识别出是德国 IP $\to$ 根据 tax_settings 表找到德国税率（19%） $\to$ 实时计算并返回含税价格。Logto 用户资料：Logto 的用户信息中可能包含国家信息，但这通常不如 IP 或收货地址准确。

-- 1. 订单主表
CREATE TABLE orders (
    id SERIAL PRIMARY KEY, -- MySQL 使用 id INT AUTO_INCREMENT PRIMARY KEY
    order_no VARCHAR(20) NOT NULL UNIQUE,
    user_id VARCHAR(50) NOT NULL,
    currency VARCHAR(10) NOT NULL,
    total_price DECIMAL(10, 2) NOT NULL,
    status VARCHAR(20) DEFAULT 'PAID',
    tracking_number VARCHAR(50),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_orders_user_id ON orders(user_id);
CREATE INDEX idx_orders_created_at ON orders(created_at);

-- 2. 订单明细表 (商品快照)
CREATE TABLE order_items (
    id SERIAL PRIMARY KEY,
    order_id INT NOT NULL REFERENCES orders(id) ON DELETE CASCADE,
    product_id VARCHAR(50) NOT NULL,
    product_name VARCHAR(255) NOT NULL,
    image_url VARCHAR(255),
    quantity INT NOT NULL,
    unit_price DECIMAL(10, 2) NOT NULL
);
CREATE INDEX idx_order_items_order_id ON order_items(order_id);

-- 3. 退款申请表
CREATE TABLE refund_requests (
    id SERIAL PRIMARY KEY,
    order_id INT NOT NULL UNIQUE REFERENCES orders(id) ON DELETE CASCADE,
    reason VARCHAR(100) NOT NULL,
    details TEXT,
    status VARCHAR(20) DEFAULT 'PENDING',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
